🎸 Agregar una GUÍA (Bajo / Guitarra / Piano...)

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Crear el HTML de la guía guias/slug-cancion-bajo.html Copiar el template de guias/vuela-vuela-bajo.html y adaptarlo. Obligatorio
2 Agregar el instrumento al mapa guias.js "slug-cancion": ["bajo"], Obligatorio Slug automático
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ NO hay que tocar letras.js. El botón 🎸 Bajo se activa solo.
📝 Ejemplo: "vuela-vuela": ["bajo"], en guias.js + archivo guias/vuela-vuela-bajo.html

📋 Agregar un SETLIST (Ensayo o Show) al portal NUEVO

🎯 ¿Cuándo se hace esto? Cuando querés que un ensayo o show quede fijo en el HTML (que lo vean todos), no solo en tu navegador.
💡 Recordá: los setlists armados desde repertorio.html viven en el localStorage de tu navegador. Para que TODOS los vean, hay que pasarlos al HTML.
⌨️ ¿Cómo abrir la consola del navegador?
Presioná Ctrl + Shift + I (la tecla Shift es la que tiene la flecha ⬆ arriba) al mismo tiempo.
También podés usar: F12 · o clic derecho → Inspeccionar → pestaña "Console".
⚠️ Solo funciona en navegadores de escritorio (Chrome, Edge, Firefox). En celular no se puede.
# ¿Qué toco? ¿Dónde? ¿Qué hago?
1 Armar el setlist repertorio.html Marcar canciones → click en "📋 Armar setlist". Completar tipo (ensayo/show), nombre, fecha, horario y lugar. Guardar. Obligatorio
2 Abrir la consola del navegador Navegador de escritorio Presionar Ctrl + Shift + I (o F12) → ir a la pestaña "Console".
La tecla Shift tiene la flecha ⬆ arriba. Sirve para mayúsculas también. Obligatorio
3 Pegar el extractor universal Consola del navegador Pegar este script (funciona para TODOS los setlists, no hay que cambiar el ID): (function() { const STORAGE_KEY = 'uranthia-setlists'; const setlists = JSON.parse(localStorage.getItem(STORAGE_KEY) || '[]'); if (setlists.length === 0) { console.error('❌ No hay setlists guardados.'); return; } console.table(setlists.map((s, i) => ({ '#': i + 1, 'ID': s.id, 'Nombre': s.nombre, 'Fecha': s.fecha, 'Canciones': s.canciones.length }))); let setlist; if (setlists.length === 1) { setlist = setlists[0]; } else { const opciones = setlists.map((s, i) => `${i + 1}. ${s.nombre} (${s.fecha})`).join('\n'); const eleccion = prompt( `¿Cuál setlist extraer?\n\n${opciones}\n\nNúmero:`); const idx = parseInt(eleccion, 10) - 1; if (isNaN(idx) || idx < 0 || idx >= setlists.length) return; setlist = setlists[idx]; } const canciones = setlist.canciones.map(c => { if (c.titulo) return c.titulo; const partes = c.key.split('|'); return partes[partes.length - 1] || 'Sin título'; }); const objetoFijo = { id: `setlists/${setlist.id}.html`, tipo: setlist.tipo || 'ensayo', nombre: setlist.nombre || `Ensayo del ${setlist.fecha}`, fecha: setlist.fecha, horario: setlist.horario || '', lugar: setlist.lugar || '', canciones: canciones.length, esFijo: true, _cancionesDetalle: canciones, _notas: setlist.notas || '', _creado: setlist.creado || '' }; console.log(JSON.stringify(objetoFijo, null, 2)); copy(JSON.stringify(objetoFijo, null, 2)); })(); Obligatorio Copia automática
4 Copiar el objeto JSON Consola del navegador El script te muestra el objeto en pantalla y lo copia solo al portapapeles.
Si tenés varios setlists, te va a preguntar cuál querés por número.
En la consola aparece un JSON con id, tipo, nombre, fecha, horario, lugar, canciones, etc.
5 Crear el HTML del setlist fijo setlists/nombre-del-setlist.html Pedirle al asistente que genere el HTML con el formato del 1er ensayo. O copiar uno existente y adaptarlo (cambiar SETLIST_ID, CANCIONES_BASE, NOMBRE_SETLIST, FECHA_SETLIST, URL_SETLIST). Obligatorio
6 Agregar el objeto a los fijos index.html Buscar SETLISTS_FIJOS y pegar el objeto copiado antes del ];: { id: 'setlists/ensayo-2026-XX-XX.html', tipo: 'ensayo', nombre: 'TITULO DEL SETLIST', fecha: '2026-XX-XX', horario: '21:00', lugar: 'CASA ATZY-SANTI', canciones: XX, esFijo: true }, Obligatorio
7 Subir todo a GitHub — Subir el HTML nuevo (dentro de setlists/) y el index.html modificado. Esperar 1-3 min. Ctrl + F5.
✅ Resultado: el setlist aparece en el portal para todos los usuarios, no solo en tu navegador.
📝 Ejemplo: id: 'setlists/ensayo-2026-10-21.html' + archivo setlists/ensayo-2026-10-21.html
⚠️ OJO: Si el id del objeto no coincide con el nombre del archivo → 404.
💡 Tip: ¿No aparece nada en la consola? Asegurate de estar en el mismo navegador donde armaste el setlist (el localStorage es por navegador).

🧠 Cómo funciona botones.js

🎯 Regla del slug: primero busca en MAPA_LETRAS, si no encuentra, lo genera automático desde el título.
Botón ¿Necesita MAPA_LETRAS? ¿Qué necesita?
▶ YouTube ❌ No Slug auto youtube.js con el slug → URL
🎸 Bajo ❌ No Slug auto guias.js con el slug → ["bajo"]
📄 Letra ✅ Sí letras.js con el título → slug

⚠️ Reglas de oro (definitivas)

# Regla Por qué
1 Los títulos SIEMPRE en MAYÚSCULAS SIN ACENTOS. El slug se genera desde el título. Si tiene acentos, no coincide.
2 El slug siempre en minúsculas, sin acentos, con guiones. Ej: TE BESE → te-bese. Si no coincide con el archivo, no funciona.
3 MAPA_LETRAS solo tiene canciones con HTML de letra real. Si no, el botón 📄 Letra apuntaría a un archivo que no existe → 404.
4 Los 3 mapas van en la raíz del repo. No en subcarpetas. Los HTML los cargan desde ahí.
5 Nunca toques botones.js para agregar contenido. Ese archivo es solo para las funciones. Se toca solo si mejorás el sistema.
6 Cada vez que cambies botones.js, subí el ?v=N en los HTML. Evita caché. Ej: ?v=3 → ?v=4.
7 Después de subir a GitHub, esperá 1-3 min y hacé Ctrl + F5. GitHub Pages tarda en actualizar. Sin Ctrl+F5 el navegador usa caché viejo.
