📋 Flujo de Trabajo v2
🎉 NUEVA VERSIÓN: Los botones ▶ YouTube y 🎸 Bajo ahora generan el slug automáticamente desde el título.
Ya NO hace falta agregar la canción a letras.js para que funcionen esos botones.
Excepción: El botón 📄 Letra sí lo necesita (porque el HTML tiene que existir).
🎯 Regla de oro: cada acción tiene sus pasos exactos. Seguí la tabla y no te vas a perder.
📌 Recordá: el slug es el nombre en minúsculas, sin acentos, con guiones. Ej: TE BESE → te-bese.

🔄 ¿Qué cambió respecto a la v1?

❌ Antes (v1)

  • ▶ YouTube necesitaba MAPA_LETRAS
  • 🎸 Bajo necesitaba MAPA_LETRAS
  • Había que agregar TODA canción a letras.js
  • Mucho ida y vuelta para activar botones

✅ Ahora (v2)

  • ▶ YouTube genera slug automático

🎸 Agregar una GUÍA (Bajo / Guitarra / Piano...)

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Crear el HTML de la guía guias/slug-cancion-bajo.html Copiar el template de guias/vuela-vuela-bajo.html y adaptarlo. Obligatorio
2 Agregar el instrumento al mapa guias.js "slug-cancion": ["bajo"], Obligatorio Slug automático
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ NO hay que tocar letras.js. El botón 🎸 Bajo se activa solo.
📝 Ejemplo: "vuela-vuela": ["bajo"], en guias.js + archivo guias/vuela-vuela-bajo.html

▶ Agregar un ENLACE de YouTube

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Agregar una línea youtube.js "slug-cancion": "https://youtu.be/XXXXX", Obligatorio Slug automático
2 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ NO hay que tocar letras.js. El botón ▶ YouTube se activa solo.
📝 Ejemplo: "vuela-vuela": "https://www.youtube.com/watch?v=XXXX",

📄 Agregar una LETRA

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Crear el HTML de la letra letras/slug-cancion.html Copiar el template de letras/la-fuerza-del-destino.html y adaptarlo. Obligatorio
2 Agregar el slug al mapa letras.js 'TITULO EN MAYUSCULAS': 'slug-cancion', Obligatorio
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
⚠️ OJO: Este es el único caso donde hay que tocar letras.js.
📝 Ejemplo: 'TE BESE': 'te-bese', en letras.js + archivo letras/te-bese.html
💡 Motivo: el botón 📄 Letra apunta a un HTML específico. Si no está en MAPA_LETRAS, apuntaría a un archivo que no existe → 404.

✅ Resultado: la canción aparece en el repertorio. Los botones ▶, 📄 y 🎸 se activan solos si existen sus archivos.
📝 Ejemplo: { titulo: 'TE BESE', artista: 'Ragazzi' },

🧠 Cómo funciona botones.js

🎯 Regla del slug: primero busca en MAPA_LETRAS, si no encuentra, lo genera automático desde el título.
Botón ¿Necesita MAPA_LETRAS? ¿Qué necesita?
▶ YouTube ❌ No Slug auto youtube.js con el slug → URL
🎸 Bajo ❌ No Slug auto guias.js con el slug → ["bajo"]
📄 Letra ✅ Sí letras.js con el título → slug

⚠️ Reglas de oro (definitivas)

# Regla Por qué
1 Los títulos SIEMPRE en MAYÚSCULAS SIN ACENTOS. El slug se genera desde el título. Si tiene acentos, no coincide.
2 El slug siempre en minúsculas, sin acentos, con guiones. Ej: TE BESE → te-bese. Si no coincide con el archivo, no funciona.
3 MAPA_LETRAS solo tiene canciones con HTML de letra real. Si no, el botón 📄 Letra apuntaría a un archivo que no existe → 404.
4 Los 3 mapas van en la raíz del repo. No en subcarpetas. Los HTML los cargan desde ahí.
5 Nunca toques botones.js para agregar contenido. Ese archivo es solo para las funciones. Se toca solo si mejorás el sistema.
6 Cada vez que cambies botones.js, subí el ?v=N en los HTML. Evita caché. Ej: ?v=3 → ?v=4.
7 Después de subir a GitHub, esperá 1-3 min y hacé Ctrl + F5. GitHub Pages tarda en actualizar. Sin Ctrl+F5 el navegador usa caché viejo.
