📋 Flujo de Trabajo
🎯 Regla de oro: cada acción tiene sus pasos exactos. Seguí la tabla y no te vas a perder.
📌 Recordá: el slug es el nombre en minúsculas, sin acentos, con guiones. Ej: TE BESE → te-bese.

➕ Agregar una CANCIÓN al repertorio

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Agregar la canción al array repertorio.html Buscar el estilo y subgrupo donde va. Agregar dentro de canciones: { titulo: 'TITULO EN MAYUSCULAS', artista: 'Artista' }, Obligatorio
2 (Opcional) Agregar link de YouTube youtube.js "slug-cancion": "https://youtu.be/XXXXX", Opcional
3 (Opcional) Agregar letra letras.js + letras/slug.html 'TITULO EN MAYUSCULAS': 'slug-cancion', + crear el HTML. Opcional
4 (Opcional) Agregar guía guias.js + guias/slug-bajo.html "slug-cancion": ["bajo"], + crear el HTML. Opcional
5 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ Resultado: la canción aparece en el repertorio. Los botones ▶, 📄 y 🎸 se activan solos si existen sus archivos.
📝 Ejemplo: para agregar "TE BESE" al repertorio, dentro del subgrupo "Pop Hombres":
{ titulo: 'TE BESE', artista: 'Ragazzi' },

▶ Agregar un ENLACE de YouTube

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Agregar una línea youtube.js "slug-cancion": "https://youtu.be/XXXXX", Obligatorio
2 Verificar que la canción esté en el repertorio repertorio.html Buscar el título en el array REPERTORIO. Debe estar en MAYÚSCULAS SIN ACENTOS. Obligatorio
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ Resultado: el botón ▶ YouTube aparece en el repertorio y en todos los setlists donde esté la canción.
📝 Ejemplo: "te-bese": "https://www.youtube.com/watch?v=h1r3GhIjjiA",

📄 Agregar una LETRA

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Crear el HTML de la letra letras/slug-cancion.html Copiar el template de letras/la-fuerza-del-destino.html y adaptarlo. Obligatorio
2 Agregar el slug al mapa letras.js 'TITULO EN MAYUSCULAS': 'slug-cancion', Obligatorio
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ Resultado: el botón 📄 Letra se activa en el repertorio y en los setlists.
📝 Ejemplo: 'TE BESE': 'te-bese', en letras.js + archivo letras/te-bese.html

🎸 Agregar una GUÍA (Bajo / Guitarra / Piano...)

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Crear el HTML de la guía guias/slug-cancion-bajo.html Copiar el template de guias/te-bese-bajo.html y adaptarlo. Obligatorio
2 Agregar el instrumento al mapa guias.js "slug-cancion": ["bajo"], Obligatorio
(podés poner varios: ["bajo", "guitarra"])
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ Resultado: el botón 🎸 Bajo se activa aunque la canción no tenga letra.
📝 Ejemplo: "te-bese": ["bajo"], en guias.js + archivo guias/te-bese-bajo.html

📋 Agregar otro SETLIST

# ¿Qué toco? ¿Dónde? ¿Qué agrego?
1 Crear el HTML del setlist setlists/ensayo-AAAA-MM-DD.html Copiar un setlist existente y adaptar: nombre, fecha, lista de canciones. Obligatorio
2 Verificar la línea de scripts Dentro del setlist <script src="../youtube.js"></script> <script src="../letras.js"></script> <script src="../guias.js"></script> <script src="../botones.js?v=3"></script> Obligatorio
3 Guardar y subir a GitHub — Esperar 1-3 min. Ctrl + F5.
✅ Resultado: el setlist funciona con todos los botones (▶, 📄, 🎸) actualizados.
💡 Tip: copiá el archivo de un setlist existente y cambiá solo lo necesario. NO toques la línea de scripts.

⚠️ Reglas de oro (no te olvides)

# Regla Por qué
1 Los títulos SIEMPRE en MAYÚSCULAS SIN ACENTOS. El slug se genera desde el título. Si tiene acentos, no coincide.
2 El slug siempre en minúsculas, sin acentos, con guiones. Ej: TE BESE → te-bese. Si no coincide con el archivo, no funciona.
3 Nunca toques botones.js para agregar contenido. Ese archivo es solo para las funciones. Se toca solo si mejorás el sistema.
4 Cada vez que cambies botones.js, subí el ?v=N en los 4 HTML. Evita caché. Ej: ?v=3 → ?v=4.
5 Después de subir a GitHub, esperá 1-3 min y hacé Ctrl + F5. GitHub Pages tarda en actualizar. Sin Ctrl+F5 el navegador usa caché viejo.
